✓公開用リポジトリに載せるもの

  • 実行バイナリ — ビルド済みのアプリ本体（.dmg / .zip / .app）を Releases に添付
  • スクリプト — 導入や補助のためのスクリプトのみ
  • この紹介サイト — GitHub Pages のページ一式
  • 導入手順などの案内文（README）

✕載せないもの

  • ソースコード — 8本とも公開しません
  • Xcode プロジェクトやビルド前の開発ファイル一式
  • アプリごとの開発用リポジトリ — すべて非公開のまま、リンクも張りません
  1. 1. 開発は非公開で
    8本の開発用リポジトリは Private のまま維持し、ソースコードは外部に出しません。
  2. 2. 成果物だけを集約
    ビルドした実行バイナリとスクリプトだけを、公開用リポジトリの Releases に置きます。
  3. 3. 更新は差し替えだけ
    新バージョンはバイナリを差し替えて Release を更新。サイトの説明も同じリポジトリで直します。

導入の流れ

入手先は公開用リポジトリひとつだけです。その Releases から、使いたいアプリの最新版をダウンロードしてください。

1

公開用リポジトリで入手する

yusukehori.github.io の Releases を開き、アプリの .dmg（または .zip）をダウンロードします。スクリプト形式で配るものは、内容を確認してから実行してください。

2

アプリケーションフォルダへ

.dmg を開いてアプリを「アプリケーション」へドラッグ。初回は右クリック →「開く」で Gatekeeper を通過させる場合があります。

3

必要な権限を許可する

Bluetooth、アクセシビリティなど、アプリごとに必要な権限は「システム設定 → プライバシーとセキュリティ」で許可してください。
