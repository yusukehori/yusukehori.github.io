GitHub Pages で公開します

独自ドメインは使わず、GitHub の標準ドメインで公開します。紹介サイトは GitHub Pages、アプリ本体の配布は各リポジトリの GitHub Releases — 役割をこの2つに分けます。Sparkle を使う場合の appcast.xml も、同じ Pages 上に置けます。

https://yusukehori.github.io/ ↗
  1. 1. 公開用リポジトリを作る
    yusukehori / yusukehori.github.io を Public で作成し、このサイトのファイルを置きます。
  2. 2. Pages を有効にする
    リポジトリの Settings → Pages で公開元ブランチを選ぶと、上の URL でそのまま公開されます。カスタムドメイン欄は空のままにします。
  3. 3. 更新は push するだけ
    アプリの追加や説明の変更は、ファイルを更新して push すれば自動で反映されます。

導入の流れ

サイトは GitHub Pages、配布は GitHub Releases です。各リポジトリの Releases から最新版を入手してください。

1

GitHubで入手する

各カードの「GitHub」からリポジトリを開き、Releases にある .dmg（または .zip）をダウンロードします。

2

アプリケーションフォルダへ

.dmg を開いてアプリを「アプリケーション」へドラッグ。初回は右クリック →「開く」で Gatekeeper を通過させる場合があります。

3

必要な権限を許可する

Bluetooth、アクセシビリティなど、アプリごとに必要な権限は「システム設定 → プライバシーとセキュリティ」で許可してください。
